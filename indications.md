# Cómo empezar

- Necesitás Node.js, Git y una carpeta vacía.
- En esa carpeta, ejecutá: npx skills add challengepost/learn-ai-basics --all -y
- Abrí tu agente ahí y decile "run 1-start".

# Requisitos obligatorios

- El proyecto tiene que ser nuevo y empezar desde una carpeta vacía durante el período de la hackathon. Podés usar ideas viejas, pero no código viejo.
- Tenés que construirlo usando las skills.
- El repo público tiene que incluir los archivos scope.md, prd.md y spec.md que generan las skills.

# Qué entregar

- Un video demo de 1 a 3 minutos (alcanza con una grabación de pantalla). Es clave, porque los jueces no van a ejecutar tu código.
- La URL de un repo público en GitHub, GitLab o Bitbucket.
- Una descripción corta: qué hace, para quién es y qué aprendiste.

# Premios ($2.500 USD en total)

1.º lugar: $1.250, más una mención en el newsletter y las redes de Devpost.
2.º lugar: $750.
3.º lugar: $500.

Todos los que entreguen un proyecto válido reciben un badge de Devpost Learn.

# Criterios de evaluación

- Diseño: que sea una experiencia de producto completa y coherente, no solo algo técnico.
- Innovación: qué tan creativa y distinta es la idea.
- Presentación: que el video muestre la app funcionando de punta a punta y explique qué problema resuelve y para quién.
